# 벨루아 카페 홈페이지 created by tuan anh 

바로크풍 분위기를 담은 카페 벨루아의 반응형 소개 페이지입니다. 별도의 빌드 도구나 패키지 설치 없이 브라우저에서 바로 열 수 있습니다.

## 주요 기능

- 다크 모드와 라이트 모드 전환
- 커피, 시그니처, 디저트 메뉴 필터
- 카페 소개, 시즌 메뉴, 매장 위치와 운영 시간 안내
- 데스크톱과 모바일 화면에 맞춘 반응형 레이아웃
- 운영자 이메일 링크

## 실행 방법

`index.html` 파일을 웹 브라우저에서 열면 됩니다. 별도의 개발 서버나 의존성 설치는 필요하지 않습니다.

## 파일 구성

```text
.
├── index.html   # 페이지 구조, 스타일, 메뉴 필터 및 테마 전환
└── Readme.md    # 프로젝트 안내
```

## 사용 기술 및 리소스

- HTML, CSS, Vanilla JavaScript
- Google Fonts의 Cormorant Garamond 및 Noto Serif KR
- Unsplash 이미지

글꼴과 이미지는 외부 URL에서 불러오므로 해당 리소스를 표시하려면 인터넷 연결이 필요합니다.

## 운영 전 확인 사항

페이지에 표시된 주소, 전화번호, 운영 시간, 메뉴와 가격은 예시 정보입니다. 실제 매장 정보에 맞게 `index.html`에서 수정해 주세요.
